
# Secure Auth System 🔐

A Node.js authentication system using Express, MongoDB, and bcrypt.

## 🚀 Features
- User Registration
- Password hashing using bcrypt
- Login Authentication
- MongoDB database connection
- Secure password storage

## 🛠 Tech Stack
- Node.js
- Express.js
- MongoDB
- Mongoose
- bcrypt

## ⚙️ Installation

1. Clone the repository:
   git clone https://github.com/Bhuvana-Hullur14/secure-auth-system.git

2. Install dependencies:
   npm install

3. Create a .env file and add:
   MONGO_URI=your_mongodb_connection_string

4. Run the server:
   npm start
